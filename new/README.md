## 保留的竞赛助手流程

入口为 `/competitions/recommend`。10个基础回合包含13个作答栏，可选预设项、逐题填写最多200字或结合两者；允许“没有／暂不确定”，支持已答题导航及最后核对，不提供额外AI补问或总补充框。文字明确更正优先，复合选项只取可确认范围；兴趣、意愿和建议任务不能变成实际能力，未知不等于缺少或零基础。

完整竞赛目录进入模型输入，不经旧候选池筛选。保留 `deepseek-flash`、思考开启、默认 `high`、一次正常报告调用及按需托管联网；现有资料足以说明准备方向时不强制检索，不为凑数遍查所有未知。目录保留任务、赛道、资格例外、费用承担、原届次、资料状态及来源；输入容量由随附官方tokenizer离线校验，超限明确失败，不截断目录。用户累计内容限制与完整系统上下文分别计算。

普通报告仍目标6—8个不同赛事，依据不足少推或零推荐。重点赛事仅在真实多维适配且无已知资格、费用、方式硬冲突时纳入；保留博士/非全日制、年龄与注册时点、个人/集体、课程成果复用等条件，不把历史资料升级为当前可报。

总期限180秒，覆盖排队及最多一次自动重试；默认档位和受核验回退逻辑保持。刷新、关页及断线不会取消已派发任务，同一浏览器可恢复最近一份；草稿和已结束任务/结果按24小时规则保留并支持清除。重试重置上一轮内容，不把两次报告拼接。没有新增账号、报告历史、下载或新报告收藏；既有“我的竞赛”保留原行为。

报告末尾保留Emily微信弹窗和竞赛组队入口，不自动把赛事对应到群。8张公开组队二维码及两个同名商赛入口保留，其历史截止时间为北京时间2026-11-27 00:00；到期停止展示并引导联系Emily，不保证旧码长期有效。

## 卡片与协议实验

内部卡片报告保留AI画像、逐张完整推荐、桌面弹窗／手机底部详情面板、全文复制和失败标记。完整条目校验后沿既有流式事件持久化并交付；点击详情不再次调用AI。旧Markdown与保存的 `discovery-cards.v1` 记录均可恢复读取。

仅被推荐的赛事附上本次冻结目录的通用资料、原届次/范围、状态、来源及合法站内入口，不把完整135项目录打入浏览器，也不让模型改写静态资料。模型个性化判断必须独立审阅，不能因附带资料正确就认定其资格、预算或推荐理由正确；静态来源与本轮新增联网来源分开理解。来源地址不自动等于报名入口，没有可靠入口时只保留核验来源和已有站内详情。

源码保留JSON、封闭文本、中文Markdown、资料展开及提示词范围等私有实验臂，用于比较画像、首项完整推荐和完整报告的可用时间。中文Markdown可在确认上游正常 `stop`、收到 `DONE` 且结语完整时省略结束标记；裸EOF、缺字段、截断、拒绝或半截标记仍失败。普通生成参数、全目录、顺序与业务规则不因展示协议改变；没有增加AI格式修复调用。来源身份检查、结构完整性和正文长度都不等于内容质量验收。

## 运行与验证

先在本目录准备Node24.22.1、pnpm11.19.0、PostgreSQL17.11的完整 `.runtime` 工具目录，直接安装锁定依赖；然后才使用：

```sh
./saitu setup
./saitu build
./saitu start --open
./saitu status
./saitu stop
./saitu dev --open
./saitu rebuild --open
./saitu verify
```

完整首次命令及裸clone时不能先用 `./saitu pnpm install` 的原因见[恢复说明](../docs/recovery.md)。构建版3190、开发模式3191、数据库5433，与 `old/` 一次只运行一个；开发与构建模式也互斥。

`setup` 是使用者在本人机器生成新数据库、随机秘密及本地授权的显式操作，不携带原作者密钥、授权或账目。真实AI需自行配置密钥并主动调用，会产生费用；新竞赛助手授权不设金额上限，旧模块300元预算示例不是它的限额。普通构建和 `verify` 不调用付费模型；`verify` 在隔离PostgreSQL数据库执行检查、清空测试AI密钥并禁止外部网络。

真实验收脚本仍保留，但只有显式 `--live` 才执行付费请求。可先只查看清单：

```sh
.runtime/node/bin/node scripts/competitions/discovery/verify-live.mjs --list
```

私有候选选择不增加公网格式控制入口。旧v13提示词和独立失败记录保留，普通旧任务继续按自己的展示版本读取；不得用新版静态资料或样式变化冒充旧模型输出。
