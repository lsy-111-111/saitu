## 竞赛助手

入口为 `/competitions/recommend`。乐乐通过10个基础回合、13个作答栏了解学生情况，每栏可选择选项、填写最多200字文字或结合两者；“没有／暂不确定”也是有效回答。支持上一题、已答题导航和最终答案核对，不再提供总补充框或AI补问。逐题文字与选项合并理解，明确文字更正优先，无法消解的矛盾保持未知，不把兴趣和意愿写成已有能力。

完整竞赛目录进入模型输入，不走旧候选池筛选。模型使用 `deepseek-flash`、思考开启、默认 `high` 和按需托管联网；资料足够时不强制搜索，仅核查会改变名单或关键条件的缺口。报告为中文Markdown，目标6—8个不同赛事，依据不足可少推或零推荐，支持来源链接、站内详情白名单入口与全文复制。未知画像不硬凑具体推荐，也不等于零基础。

完整目录保留任务、赛道、资格例外、费用承担、届次、状态和来源。中国国际大学生创新大赛及“挑战杯”创业计划竞赛包含带来源的2026年资料；仅在真实适配门槛满足且无已知硬冲突时尽量纳入，不固定第一或额外加名额。历史报名时间不能改写为当前可报，报名费不能替代个人全程总费用，目录核查日期不等于本轮联网日期。

完整目录放在明确标注为数据的系统资料区，学生回答单独进入用户消息。随附官方tokenizer在本机离线计算输入容量，超限明确失败，不静默截断或删掉赛事；历史实测的托管入口累计用户内容32K限制与模型一般上下文容量分别处理。相关第三方许可见[通知](../THIRD_PARTY_NOTICES.md)。

总时限180秒，包含排队和最多一次自动重试，不因开始输出而延长。策略保留 `max` 已派发且150秒仍无正文时，在剩余时间内回退 `high` 的处理；默认直接为 `high`，不会伪称先发生过 `max` 超时。同一会话实际超时与账目可核对时，手动重试可继承相应档位依据，但有自己新的180秒截止，不覆盖原失败。

刷新、关页或断线不取消后台任务；同一浏览器可恢复最近一份。草稿自最后编辑起、服务端任务/结果自结束起各按24小时保留，可主动清除。重试会重置上一轮正文，避免拼接两次回答。没有新增账号、报告历史、下载或新报告收藏；既有“我的竞赛”记录保持原行为。正文长度检查只能拦截明显不完整答案，不能保证事实或推荐正确。

报告末尾保留Emily微信弹窗及组队页链接，不建立每个赛事与某个群的绑定。组队页保留8张已公开二维码，含两个同名商赛入口；历史组队码截止时间为北京时间2026-11-27 00:00，到期后页面及图片接口停止展示旧码并引导联系Emily。品牌和联系素材保留，不作为当前二维码必然有效的保证。

## 运行与验证

在本目录准备好 `.runtime/node`、`.runtime/pnpm`、`.runtime/postgres`，并直接使用准备好的Node/pnpm安装 `pnpm-lock.yaml` 锁定依赖后：

```sh
./saitu setup
./saitu build
./saitu start --open
./saitu status
./saitu stop
./saitu dev --open
./saitu rebuild --open
./saitu verify
```

构建版3190、开发模式3191、数据库5433；与 `new/` 一次只运行一个。工具目标为Mac arm64、Node24.22.1、pnpm11.19.0、PostgreSQL17.11，完整首次准备命令见[恢复说明](../docs/recovery.md)。安装依赖后也可执行 `./saitu pnpm typecheck`、`lint` 等命令。

`setup` 在使用者本人机器生成新的私有配置、数据库和授权，不带原作者密钥、授权或历史账目。AI密钥由使用者自行填写；新竞赛助手代码的本地授权不设金额上限，不能把旧模块预算示例当作其上限。启动、构建和离线验证不主动发送真实验收请求；真实使用或带 `--live` 的验收会产生费用。

`./saitu verify` 在初始化后执行类型、lint、全部单元测试与隔离PostgreSQL测试，清空测试AI密钥并禁止外部网络。可先用下面的只读清单查看合成画像；它不会运行付费验收：

```sh
.runtime/node/bin/node scripts/competitions/discovery/verify-live.mjs --list
```
