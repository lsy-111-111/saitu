## 公开化修改

本仓库是可审阅的源码交付，不是原本机运行包或生产服务器磁盘的完整镜像。公开化处理包括：

- 整理根说明、各版README、恢复说明与许可，移除本机私有路径、原服务器IP/主机指纹、默认私人密钥路径及“已有密钥/已有授权可直接沿用”的表述。
- 服务器客户端改为使用部署者显式提供的 `SAITU_SSH_HOST`、`SAITU_SSH_HOST_FINGERPRINT`、`SAITU_SSH_KEY_FILE`，保留严格主机密钥校验，不默认指向原服务器。
- 不带 `.env.local`、`.local` 数据库/凭据/账目、`.runtime` 工具、`node_modules`、构建、私人会话或原Git历史；各副本在使用者机器上重新准备环境。
- 保留业务源码、公开品牌/联系方式/二维码和源码实际引用的必要素材及赛事证据；不把整个历史产物目录作为运行数据迁入。

这些修改不意图改变原业务行为，但会改变文件内容与公开交付集合，故不能把公开目录的哈希当作原归档哈希。导出文件清单、验证命令与公开证据以[验证目录](validation/README.md)中的实际记录为准。

## 验收状态

`old/README.md` 的历史耗时数字仅描述对应历史批次，不等于本次导出在新环境重跑的结果。`new/README.md` 保留候选未通过发布门槛的说明；卡片界面、协议、结构校验或离线测试通过，不等于事实正确、推荐质量通过或明显快于旧版。

历史 `.local/checks/` 中未在公开验证目录列明的原始报告、计费记录、捕获文件和人工审阅不属于本次交付，不能假定仓库包含这些文件。新实验、离线反事实重放和单例诊断也不能覆盖原失败记录或充当正式验收成功。

历史附件不是完整实验归档。原包部分历史元数据引用的路径本就不存在；公开交付只确认当前运行及直接源码依赖的材料闭包，不宣称整套历史实验均可重放。受硬SHA绑定的证据保留原始字节，其他附件中的私有路径元数据按公开化要求处理；范围以验证清单为准。

源码可重建不等于复原私人服务状态：旧数据库、签名秘密、调用授权、服务商密钥、历史消费与任务恢复凭据均不公开，也不会自动迁入新的本地实例。
