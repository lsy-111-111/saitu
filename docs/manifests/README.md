# 公开源码文件清单

[old.json](old.json) 与 [new.json](new.json) 记录各版本导出文件的路径、大小、当前SHA-256及来源SHA-256。存在公开化调整的文件逐项说明原因。清单只覆盖对应版本的源码与随附资产，不包括根说明、本清单自身或被忽略的验证产物。

来源中的私人历史记录已排除，或仅以中性兼容说明替代；不会发布原内容。实际环境配置、数据库、秘密、运行工具、依赖、构建与原Git历史不在导出范围，也不提供其内容哈希。当前工作区源码冻结后已再次核验，原文件未被本次导出修改。

旧版原发布清单1534项验证通过，公开集合因必要清理而不同。新版运行源码绑定记录在对应清单中。恢复运行仍需自行准备工具、依赖和私有配置，参见[恢复说明](../recovery.md)。
