## 数据库隔离与验证过程

现有本机应用监听 IPv4 回环地址。本次临时测试集群独立监听 IPv6 回环地址，使用各版本专属的随机测试数据库及最小权限角色。测试进程临时传输适配只把数据库 TCP 连接导向独立集群，保留产品固定回环地址的校验逻辑；连接前断言真实远端地址及数据库数据目录均属于测试集群。适配不进入仓库或生产代码。外部网络被验证预加载脚本禁止，不携带实际 API 密钥。

首轮出现 PostgreSQL 驱动解析 IPv6 URL 及产品固定端点校验不匹配；旧版验证进程还曾额外设置本机模式，影响历史批次授权测试。修正测试环境后重新执行完整测试，上表为最终结果。各次失败和处理原因保留在摘要中，不当作产品改造或质量提升。

## 证据与公开化变动

每版保留709个现存必要研究附件。328个完整字节保护文件及全部运行/作品证明哈希绑定校验通过；143个非绑定JSON只替换原作者电脑上的绝对路径，其余数据字段不变。历史日志有原包既有的失效引用，因此不承诺完整重放全部历史研究过程。
