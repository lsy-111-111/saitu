# 赛途 · saitu

赛途是面向学生的竞赛信息与选赛网站，包含赛事浏览、收藏、竞赛组队、乐乐竞赛助手及网站原有页面。品牌网站：[gzhanchuang.com](https://gzhanchuang.com)。

本仓库以 `old/`、`new/` 保存两个源码版本。交付内容是源码、必要素材、来源证据和恢复说明，**不附运行包、安装器、运行工具、依赖、数据库或密钥；裸clone后不能直接运行 `./saitu`**。

## 开始使用

先阅读[恢复与运行说明](docs/recovery.md)，选择一个版本准备环境。当前恢复目标是macOS Apple Silicon：Node.js 24.22.1、pnpm 11.19.0、PostgreSQL 17.11。

每个版本都需要自行准备 `.runtime/node`、`.runtime/pnpm`、`.runtime/postgres`。首次依赖安装必须直接使用准备好的Node/pnpm入口；安装完成后，才能使用 `./saitu setup`、`build`、`start`。初始化会创建使用者本机的新数据库、随机凭据和本地授权，不复用原作者的配置或历史数据。

两个版本使用同一组端口：网页3190、开发模式3191、数据库5433，**一次只运行一个版本**。本仓库不自动部署，也不设置自动CI；上传源码不执行真实AI请求或服务器操作。

## 功能与边界

- 统一问卷：10个基础回合、13个作答栏，选项与逐题文字结合，支持回看和核对；不追加AI追问。
- 完整竞赛目录进入模型输入；区分任务意愿、已有经历、资格例外、历史届次、费用承担和全程参加方式。
- DeepSeek流式报告、来源链接、全文复制；180秒总期限、受限并发和最多一次自动重试。
- 同一浏览器恢复最近任务；草稿和已结束的服务端结果按24小时规则保留，并提供清除入口。
- 新版本保留卡片实验与恢复兼容，但工程测试通过不等于模型事实正确、推荐质量合格或明显提速。

真实AI需要使用者自行配置服务密钥并主动提交任务，会产生服务商费用。源码不携带现成密钥、服务商余额或可沿用的私人授权。普通构建与离线验证不发送付费模型请求；新竞赛助手的本地授权代码本身不设金额上限，详见恢复说明。
